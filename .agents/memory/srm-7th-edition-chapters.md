**Why:** Earlier data files used a mix of bare "Chapter N" strings and older-edition numbering (State Plane as Ch 21, spirals as Ch 25, photogrammetry as Topic V Ch 24) that did not match the user's book; ~90 references were corrected in one pass (July 2026).
**How to apply:** Any new reading/lesson that cites the Surveyor Reference Manual must use this map; never cite a bare chapter number without its Topic.
